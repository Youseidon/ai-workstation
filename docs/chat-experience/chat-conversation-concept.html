Sign-in follows three steps: validate the input, check credentials, then create a session.

  • login-form.tsx owns the fields and validation messages.
  • sign-in.ts checks credentials and handles failures.
  • session.ts creates the session used by subsequent requests.

Where to start

For clearer error messages, start with the form. For a different sign-in method, start with the credential check.
